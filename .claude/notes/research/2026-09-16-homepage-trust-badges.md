## UX
- Viewing time: 57% above the fold, 74% in the first two screens. https://www.nngroup.com/articles/scrolling-and-attention/
- Ad-like styling or motion near the top gets ignored (banner blindness). https://www.nngroup.com/articles/banner-blindness-old-and-new-findings/
- Non-clickable items must not look clickable. https://www.nngroup.com/articles/clickable-elements/ · https://www.nngroup.com/articles/button-states-communicate-interaction/
- Trust depends on accurate, current content. https://www.nngroup.com/articles/trustworthy-design/
- Ideal number of badges: no authoritative source (UNVERIFIED); homepage simplicity argues for <= 4. https://www.nngroup.com/articles/homepage-design-principles/

## Accessibility
- An informative image containing text -> alt repeats the text. https://www.w3.org/WAI/tutorials/images/textual/ · https://www.w3.org/WAI/tutorials/images/decision-tree/
- WCAG 1.4.5 Images of Text exempts only logotypes; HTML text + icons is the fully compliant route. https://www.w3.org/WAI/WCAG22/Understanding/images-of-text.html
- Contrast applies to images of text: white on #ED1C1C = 4.39:1 (< 4.5:1 for small text). https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html
- Related items -> a list (technique H48); Safari drops list semantics with `list-style:none`, so add `role="list"`. https://www.w3.org/WAI/WCAG22/Techniques/html/H48 · https://developer.mozilla.org/en-US/docs/Web/CSS/list-style
- Don't create a landmark (`section` + aria-label) for a badge row. https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Roles/region_role

## Performance
- `width`/`height` attributes + `height:auto` prevent layout shift. https://web.dev/articles/optimize-cls
- Don't lazy-load above-the-fold images. https://web.dev/articles/browser-level-image-lazy-loading
- `fetchpriority="high"` only for the LCP image. https://web.dev/articles/fetch-priority
- Pixels needed = CSS size x device pixel ratio -> the 302px source is 1:1 at 151 CSS px on 2x screens. https://web.dev/learn/performance/image-performance
- WebP lossless is ~26% smaller than PNG (optional; ~70 KB total here). https://developers.google.com/speed/webp

## Layout options for 4 fixed items
| Option | Pros | Cons |
|---|---|---|
| **Grid 4 columns -> 2x2 via media query (chosen)** | never leaves an orphan | one media query |
| `flex-wrap` | simplest | wraps 3+1 |
| `repeat(auto-fit, minmax())` | no media query | wraps 3+1 (https://css-tricks.com/auto-sizing-columns-css-grid-auto-fill-vs-auto-fit/) |
| Horizontal scroll | keeps one row | off-screen items get missed (https://www.nngroup.com/articles/horizontal-scrolling/) |
| Marquee | eye-catching | needs a pause control (WCAG 2.2.2) and reads as an ad (https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html) |

## White-background JPG options
- (a) Designer re-export — cleanest (requested).
- (b) Flood-fill white from the image edges only — **chosen stop-gap**. A global colour-to-alpha would also erase the white text and ring (https://docs.gimp.org/3.0/en/gimp-filter-color-to-alpha.html).
- (c) `mix-blend-mode: multiply` — turns the white text grey and shifts the red. https://developer.mozilla.org/en-US/docs/Web/CSS/mix-blend-mode
- (d) White card behind the row — works, but differs from the sketch.
